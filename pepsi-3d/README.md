# Pepsi 3D मोशन ग्राफ़िक (Three.js)

कोड से बना 12 सेकंड का 3D वीडियो। इसमें बोतल नीचे से घूमते हुए ऊपर आती है, ढक्कन घूमकर खुलता है और उछलकर उड़ जाता है, कोला की बौछार और झाग निकलते हैं, लाल/सफ़ेद/नीले रिबन घूमते हैं, और आख़िर में **PEPSI · OPEN THE FIZZ** टाइटल आता है।

- `pepsi-3d-motion.mp4`: तैयार वीडियो (1920×1080, 30fps, साउंड इफ़ेक्ट्स के साथ)
- `index.html`: पूरा 3D सीन। ब्राउज़र में लाइव चलता है
- `render.cjs`: वीडियो एक्सपोर्ट करने वाली स्क्रिप्ट

## 1. ब्राउज़र में चलाना

```bash
cd pepsi-3d
npx serve .            # या: python -m http.server 8000
```
फिर `http://localhost:3000` (या 8000) खोलें। नीचे के बटन:
**Pause/Play**, **Replay**, स्लाइडर (किसी भी पल पर जाने के लिए) और **⏺ Record**। Record दबाने पर एनीमेशन शुरू से चलता है और पूरा होने पर `.webm` वीडियो डाउनलोड हो जाता है।

> three.js CDN (jsdelivr) से लोड होता है, इसलिए इंटरनेट चाहिए। ऑफ़लाइन चलाने का तरीका `index.html` के ऊपर कमेंट में लिखा है।

## 2. MP4 वीडियो ख़ुद रेंडर करना

ज़रूरत: Node.js 18+ और [ffmpeg](https://ffmpeg.org/download.html)

```bash
cd pepsi-3d
npm install
npx playwright install chromium
npm run render                # → pepsi-3d-motion.mp4
node render.cjs 1280 720 60   # अपनी चौड़ाई / ऊँचाई / fps
```
स्क्रिप्ट हर फ्रेम को हेडलेस ब्राउज़र में `window.__renderAt(t)` से बनाती है और ffmpeg से जोड़ती है। साउंड (ढक्कन घुमाने की सीटी, पॉप, फ़िज़, व्हूश, बेस हिट) भी ffmpeg से ही सिंथेसाइज़ होता है, इसके लिए कोई ऑडियो फ़ाइल नहीं चाहिए।

## 3. टाइमलाइन

| समय | क्या होता है |
|---|---|
| 0 – 2s | बोतल नीचे से घूमते हुए ऊपर आती है, कैमरा चारों ओर घूमता है |
| 2.3 – 3.8s | कैमरा ढक्कन के पास जाता है, ढक्कन घूमता है, "TWIST IT" आता है |
| 3.8s | **पॉप!** ढक्कन उड़ता है, फ़्लैश होता है, कैमरा हिलता है, "PSSHHH!" आता है |
| 3.8 – 6.5s | कोला की बौछार, झाग और रिबन बनते हैं |
| 6.5 – 7.5s | लाल/सफ़ेद/नीली डायगोनल वाइप ट्रांज़िशन |
| 7.5 – 12s | हीरो शॉट: PEPSI टाइटल, टैगलाइन और #OpenTheFizz |

## 4. अपने हिसाब से बदलना (`index.html` में)

| क्या बदलना है | कहाँ |
|---|---|
| वीडियो की लंबाई / पॉप का समय | `DURATION`, `T_POP` |
| बोतल का आकार | `profilePts` (त्रिज्या, ऊँचाई के पॉइंट) |
| लेबल का डिज़ाइन / टेक्स्ट | `labelTex` (canvas पर ड्रॉइंग) |
| ढक्कन का रंग / लोगो | `capMat`, `topTex` |
| कैमरा मूवमेंट | `camKeys` (समय, कोण, दूरी, ऊँचाई, टारगेट) |
| स्क्रीन पर टेक्स्ट | `textPlane('...')` वाली लाइनें + `updateHUD()` |
| बौछार कितनी ज़ोर की हो | `SPR` (संख्या), `sprData` में `vy` |
| चमक (glow) | `UnrealBloomPass(..., strength, radius, threshold)` |

## उपयोग से जुड़ी बात
यह एक कॉन्सेप्ट / फ़ैन-मेड प्रैक्टिस प्रोजेक्ट है, Pepsi का आधिकारिक विज्ञापन नहीं। लेबल और लोगो कोड से बनाए गए अपने डिज़ाइन हैं। "Pepsi" नाम PepsiCo का ट्रेडमार्क है, इसलिए इसे किसी कमर्शियल काम या क्लाइंट के लिए इस्तेमाल करने से पहले ब्रांड से अनुमति लें। पोर्टफ़ोलियो या सीखने के लिए इसे इस्तेमाल करते समय "concept / spec ad" लिखना ठीक रहता है।
