# YAP Digital Marketing

Agency website for **YAP Digital Marketing** — "We make brands impossible to ignore."

Static site (no build step): `index.html`, `style.css`, `script.js`.

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8000
```

Sections: Hero, About, Services, Portfolio (filterable), Why YAP, Pricing (₹8k / ₹10k / ₹13k), Client results, Payment (UPI), CTA, Contact (project brief opens WhatsApp), Footer.

To add your real UPI QR, replace the `.qr` box in the Payment section with an `<img>`.
